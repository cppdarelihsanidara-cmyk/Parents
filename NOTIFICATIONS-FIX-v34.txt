Dar El-Ihsan – Notification Fix v34

Frontend changes included in both the project root and dist/:
- Admin test button now calls the existing authenticated DE client (C.fn), which refreshes the admin session and attaches the active JWT.
- Removed direct browser calls to the batch outbox worker. Admin-created parent notifications are queued only; the scheduled worker processes them.
- Queue processing stores successful recipient deliveries and skips them on retry to avoid duplicate notifications.
- Temporary push errors are retried; permanent/expired or old-VAPID subscriptions are deactivated rather than retried forever.
- Parent subscription writes now use the endpoint unique key with an explicit PostgREST upsert and correct Prefer header.
- Corrected Android/mobile device classification; login now renews locally stored subscriptions that the server marked inactive/expired, and failed enrollment synchronization is retryable.
- Cache-busting and independent Parent/Admin version keys updated to avoid stale assets and cache resets between the two apps.

Supabase Edge Functions deployed:
- send-push-notifications: version 16 (active)
- send-push-test: version 2 (active)

Safety:
- The existing outbox cutoff is intentionally retained. Historical pending rows before 2026-11-22 13:18:55.538694 UTC are not replayed automatically.
- Existing historical failed rows are not re-sent.
- VAPID secrets/public key values were not rotated.
- The WhatsApp Cron job and its schedule were not changed.

Deployment:

- Or replace the whole Parents-main folder with the complete archive.
